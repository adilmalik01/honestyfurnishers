# Honesty Furnishers

## Overview

Marketing website for Honesty Furnishers, a furniture brand. The site presents the catalog, services, about content, and a contact form.

## Features

- Home page with hero, featured products, stats, services, and about sections
- Products, services, and about pages
- Contact form via EmailJS
- Social links and Framer Motion section animation

## Technologies Used

Next.js 15 · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · EmailJS

## Project Structure

`src/app` (routes), `src/components` (Hero, Navbar, Footer, contact), `src/data.ts`

## Installation

```bash
npm install
npm run dev
```

## Environment Variables

EmailJS keys in `.env.local`. Use the names already referenced in `src/components/contactComponent.tsx`. Do not commit secrets.
